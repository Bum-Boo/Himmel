# Himmel downstream scope

Himmel adds a compact downstream layer to the pinned Hermes Agent baseline:

1. fail-closed included-plan quota protection;
2. bounded persona progress and status presentation;
3. allowlisted gateway restart brokering and systemd handling;
4. bounded current-session reply context;
5. Telegram rich-message policy integration;
6. turn-scoped progress/media cleanup;
7. explicit Telegram group-routing exclusions;
8. structured localized human-approval UI;
9. fresh-read Honcho identity cache invalidation.

The public repository contains the resulting full source tree. It intentionally excludes personal profiles, credentials, sessions, message history, cron history, Kanban databases, and raw local provenance patches.
